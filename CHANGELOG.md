# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-06-20

### Added

- **Premium Themes & Layouts**: Included 4 stunning visual themes (Midnight Nebula, Emerald Mint, Royal Gold, Arctic Minimal) and 3 printing layout styles (Modern Creative, Corporate Classic, Minimalist Elegant).
- **Client CRM Database**: A complete manager to add, edit, and delete client information.
- **Visual Analytics Dashboard**: Displays total earnings, pending vs paid counts, and a visual sales growth chart using Chart.js.
- **Credit Ledger (Khata Book)**: Tracks client outstanding debt and payment transactions.
- **PWA Capabilities**: Service worker caching and PWA manifest support for offline installations.
- **Offline Data Backup**: Options to download a secure JSON backup of the system data and restore it instantly.

### Changed

- Commented out the theme-color meta tag to fix firefox compatibility warning.
- Updated the header banner with developer name and email for the Digital Heroes developer submission.
