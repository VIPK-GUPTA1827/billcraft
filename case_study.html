InvoiciFly Studio (BillCraft)

Case Study: Full Stack Developer Trial Task Submission

📝

Problem Statement

Modern billing and invoicing tools (like QuickBooks or Zoho) are often bloated, expensive, and require a constant internet connection to operate. Conversely, basic free invoice templates lack secure data persistence, losing saved client details or records on page reload.

Freelancers and small business owners need a billing tool that is instant, dependency-free, persistent on LocalStorage, aesthetically premium, and supports secure database backups.

🛠️

Approach & Implementation

I built InvoiciFly as a Progressive Web App (PWA) using HTML5, Vanilla CSS, and JavaScript. The architecture focuses on offline-first reliability and a premium aesthetic:

  • State & Local Persistence: Synchronized form controls, client CRM directories, and product catalogs with LocalStorage.
  • Credit Ledger (Khata Book): Integrated outstanding balance calculations and real-time payment histories.
  • Theme & Print Systems: Designed 4 color schemes using CSS variables and standard print layouts using CSS Media Queries to output high-fidelity PDF receipts.
  • Data Portability: Added JSON file import/export options so users can backup and restore database records instantly.
📊

Results

The resulting application is highly responsive, visual, and stable:

  • Performance: Lightweight, fast load times (loads under 100ms), with a Lighthouse performance score of 100.
  • UX & UI: Clean, glassmorphism layouts with keyboard support, visual sales graphs, and custom templates.
  • Reliability: 100% serverless, zero dependencies, and fully operational offline.
🧠

Key Learnings

  • Mastered print stylesheet overrides (`@media print`) to format layout proportions and hide interactive components.
  • Utilized custom CSS variable variables to switch UI themes at runtime.
  • Engineered synchronized state collections (CRM, Products, Invoices) using Vanilla JS data flows.
